>>> 6. Alternative Concept & Complexity Analysis:
  ----------------------------------------------------------------------------------------
  Dimension             | Abstract Base Class + Virtual    | Single Class with Switch
  ----------------------+----------------------------------+-------------------------------
  Time Complexity       | O(1) constant vtable lookup      | O(1) jump table / switch
  Space Overhead        | 8 bytes (vptr); 0 unused fields  | Up to 65% wasted memory (unused
                        | (exact size per derived type)    | fields for all vehicle types)
  Open/Closed Principle | Fully Compliant (OCP adhered):   | Violates OCP: Adding new type
                        | New types added via inheritance  | requires editing core class,
                        | with zero edits to working code  | enum, and all switch branches
  Extensibility Cost    | Zero regression risk in existing | High regression risk across
                        | tested classes or fleet managers | entire monolithic codebase
